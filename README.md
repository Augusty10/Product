## 1. PrivacyNotes – Encrypted Note-Taking App

### Objective
Build a privacy-first note-taking application with client-side encryption to ensure data security.

### Key Features
- Client-Side AES Encryption (CryptoJS)  
- Offline-First (IndexedDB / localStorage)  
- Full CRUD Operations  
- Search, Pin, Archive Notes  
- Optional Cloud Sync  

### Tech Stack
- Frontend: React  
- Encryption: CryptoJS (AES)  
- Storage: IndexedDB / localStorage  

### Deliverable
Secure offline-first encrypted notes application.
